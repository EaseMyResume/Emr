# Daily Checklist (Android 16+ / API 36)

A clean, minimal dark-mode daily checklist app and home screen widget built with **Kotlin**, **Jetpack Compose**, and **Jetpack Glance**.

## Build Without Android Studio (Free via GitHub Actions)
1. Unzip `DailyChecklist-Android16.zip`.
2. Create a new repository on GitHub and upload the contents of `DailyChecklistApp/` (including `.github/workflows/build-apk.yml`).
3. Open the **Actions** tab on GitHub -> click **Build Debug APK** -> **Run workflow** (or push to `main`).
4. Once finished, download **DailyChecklist-debug-apk** (`app-debug.apk`) directly onto your Android 16+ phone and install it.
5. Long-press your home screen -> **Widgets** -> **Daily Checklist** to add the widget.
